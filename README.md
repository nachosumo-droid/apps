# SumoSoft — sitio oficial

Sitio estático (GitHub Pages). Sólo archivos del sitio: **no** contiene código de las apps, claves ni APKs.

- Precios y estado de ventas: **`config/precios.json`** (fuente única; también la lee el servidor de licencias).
  Los precios actuales son **provisorios** y deben confirmarse.
- `ventasActivas: false` → el botón Comprar sólo informa que las compras están por habilitarse.
- Las descargas de prueba se publican como *Releases* de este repositorio.
